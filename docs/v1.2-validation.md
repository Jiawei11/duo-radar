# v1.2.0 Windows validation

Tested on Windows x64 with local Chrome, 2026-10-17 (America/Chicago).

## Live inventory outside Texas

`cargo test -p apple-store-inventory-monitor live_us_nationwide -- --ignored --nocapture`

| Store | Store number | ZIP used for lookup | Result at test time |
| --- | --- | --- | --- |
| New York · Fifth Avenue | R095 | 10153 | iPhone 17 MG484LL/A: InStock |
| San Francisco · Union Square | R075 | 94108 | iPhone 17 MG484LL/A: InStock |
| Los Angeles · The Grove | R050 | 90036 | iPhone 17 MG484LL/A: InStock |

Each result was matched by the exact requested store number. This validates the nationwide query path, not every US store or future stock.

## Live cart

`cargo test -p apple-store-inventory-monitor live_us_cart_and_repeat -- --ignored --nocapture`

An isolated, initially empty browser profile selected iPhone 17 256GB Mist Blue (MG484LL/A), no trade-in, full payment, connect to any carrier later, no AppleCare. The app clicked Add to Bag, then Review Bag, and verified that exact SKU at quantity 1. Calling the same flow again verified quantity 1 without adding another item. No checkout or payment action is implemented in this flow.

The app's dedicated cart is separate from the user's daily Chrome profile. Pickup location must be confirmed manually on Apple. Duo stock has not opened at test time; Duo cart completion has not been live-tested.

## Regression checks

- `pnpm test`: includes SKU/model/color guards, quantity checking, no empty-bag inference during loading, and pause-before-clear behavior.
- `pnpm build`: TypeScript and Vite production build.
- `cargo test --workspace --lib --tests`: offline Rust regression checks. Live network tests are opt-in.
